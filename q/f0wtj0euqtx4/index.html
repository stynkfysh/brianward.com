Why I recommend the desktop

The analysis behind all three options is identical. The difference is how much supporting detail goes into the report — not how the value is determined. With good, representative photos, a desktop appraisal reaches the same reliable value conclusion a standard would, and it holds up to the same scrutiny.

Good photos of your mother's home are already available online (see below), so a site visit wouldn't add anything to the value analysis here. The desktop gives you the full, well-supported report without paying for a visit that wouldn't change the outcome.

The one case where I'd steer you to the standard instead is if the estate is being divided among several parties. It doesn't change the value — but at a sensitive time, the added thoroughness of an in-person inspection helps everyone feel confident in the report. If that's your situation, let me know.
